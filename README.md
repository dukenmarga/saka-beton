## Saka Beton
Saka Beton - Open-source app for biaxial interaction diagrams of reinforced concrete columns.

It complies with:
- SNI 2847:2019 / ACI 318-14

## Download

Current version is 1.0.0 and is available in platform Microsoft Windows and Linux.

[Download from here](https://github.com/dukenmarga/saka-beton/releases/tag/v1.0.0). 

## Capability

* Comply with SNI 2847:2019
* Ability to analyze arbitrary shape and reinforcement configurations
* Handle multi openings inside concrete boundary
* Include some common shapes: rectangle, T, L, circle, hollow-rectangle, hollow-circular
* Generate and download simple report
* Generate diagram interaction
* Export diagram interaction as TSV file
* Web user interface
